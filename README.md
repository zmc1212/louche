# 耧车 LOUCHE — 机构复刻 No.07

西汉赵过发明、王祯《农书》绘图的三脚耧车:一牛引之,耧斗调节板控制下种
开度,三条中空耧腿行进开沟下种,后拖挞覆土——「且种且耰」。三管落种
一致性 ±2% 载入断言,B 键查看复原总图。

## 机构与验算

```
尺寸(演示值):
  车轮   径一尺(0.30 m)×2,轮距 1.0 m
  耧腿   ×3,中空管,行距 0.30 m,腿尖铁刃开沟
  耧斗   种子斗 + 调节板(开度 0..100%)

下种(载入期断言):
  下种率 = 14 粒/s × 开度(三管合计,线性)
  三管一致性:20s 模拟计数差 ≤ 2%
  开度减半 → 率减半(线性断言)
```

## 试验段(时间线 44s 循环)

| 键 | 阶段 | 内容 |
| --- | --- | --- |
| 1-4 | 装配 | 车架双辕双轮 → 耧斗调节板 → 三耧腿 → 挞 |
| 5 | 播种 | 行进开沟,三管种子粒子落沟 |
| 6 | 均匀度 | 三沟落点分布(ROWS 面板) |
| 7 | 开度对比 | ←/→ 调开度看率变化 |
| 8 | 手动 | ←/→ 调开度行进 |

仪表盘:行速+下种率、三管均匀性计数条、开度板、沟内落点分布。
